# C6L Projects — GitHub Pages v3

Ready-to-publish static site for `https://siem84.github.io/`.

## Included
- English homepage: `/`
- Polish homepage: `/pl/`
- English project pages
- Polish project pages
- Real project banners from both repositories
- Main hero image
- WebP versions for faster loading + PNG fallbacks
- `robots.txt`
- `sitemap.xml`
- canonical URLs
- `hreflang` EN/PL
- Open Graph metadata
- FAQ structured data (`schema.org/FAQPage`)
- responsive desktop/mobile CSS

## Editing images
Replace files inside `assets/images/` while keeping the same filenames.

## Editing text
English text is in the root `.html` files.
Polish text is in the `pl/` folder.

## Publishing
Create/use the public repository `siem84.github.io` and upload the **contents** of this folder to the repository root.
