MeshCore + Meshtastic DualBoot

This project keeps both systems on a single M5Stack Unit C6L and lets you decide at startup which one should run.

How does DualBoot work on Unit C6L?

At startup, the OLED menu lets you choose MeshCore or Meshtastic. The selected firmware then boots normally in its own environment. On a later restart, you can select the other system.

  • MeshCore and Meshtastic on one Unit C6L
  • system selection from the OLED startup menu
  • persistent default system choice
  • only one mesh system runs at a time
  • switch systems without a full reflash

Why use it?

It is useful for comparing both ecosystems, experimenting with different mesh networks and using one C6L for different roles without keeping two separate units.
